## 遇到并解决的问题

### Ollama 工具回填返回 HTTP 400

- 现象：第一轮模型能调用 `calculator`，第二轮把工具结果发回模型时返回 HTTP 400。
- 根本原因：内部消息使用 OpenAI 风格的工具参数 JSON 字符串，而 Ollama 原生接口要求参数是对象，工具结果需要 `tool_name`。
- 解决方案：在 Ollama Provider 中单独转换消息格式，并保留上游错误正文。
- 验证结果：两轮 Agent Loop 成功，最终回答为 `计算结果为 12345 乘以 6789 等于 83810205。`
