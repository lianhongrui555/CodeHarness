# 第一阶段：最小 Agent Loop

## 目标

实现一个只依赖本地 Ollama 的命令行代码项目助手。

## 交付内容

1. Ollama Provider
2. Message 数据结构
3. Agent Loop
4. 工具注册表
5. `calculator` 工具
6. 只读 `list_files` 工具
7. 只读 `read_file` 工具
8. CLI 入口
9. 基础自动化测试

## 验收场景

### 场景 1：普通回答

```text
输入：请解释什么是 Python 虚拟环境
预期：模型直接回答，不调用工具
```

### 场景 2：数学计算

```text
输入：请计算 12345*6789
预期：Agent 调用 calculator 工具并返回 83810205
```

### 场景 3：读取项目

```text
输入：列出当前项目目录，并读取 README.md 的前 20 行
预期：Agent 调用项目工具，基于真实文件回答
```

### 场景 4：不存在文件

```text
输入：读取 not-exist.txt
预期：工具返回明确错误，Agent 不编造文件内容
```

## 暂不实现

- 写入文件
- 修改代码
- 执行任意 Shell 命令
- 自动 Git 提交
- Web 界面
- 微信小程序连接

这些能力必须在只读工具稳定后逐步加入。

## 完成标准

- `pytest` 全部通过
- CLI 可以正常启动
- Agent 能完整执行一次工具调用循环
- 工具不能访问工作目录之外的文件
- README 和工程日志同步更新
